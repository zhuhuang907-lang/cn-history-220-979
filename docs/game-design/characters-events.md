# 人物与事件：从史料到可玩叙事

本文说明如何用 `data/game/characters.json` 与 `data/game/events.json` 构建人物卡、关系网、事件链与叙事节奏。

---

### 1.2 从史料到人物属性

不要直接把“忠/奸”“勇/智”当成史实。建议分三层：

| 层 | 内容 | 来源 |
|---|---|---|
| 史实 | 生卒、籍贯、阵营、官职、事件 | 正史、编年史 |
| 评价 | 时人/史家评语、性格轶事 | 正史、笔记 |
| 设计 | 属性、技能、标签、成长曲线 | 设计抽象 |

属性映射示例：

- **统率**：独立指挥战役、治军、边疆作战。
- **武力**：个人勇武、阵战、刺杀记录。
- **智谋**：战略、谋略、外交、制度设计。
- **政治**：官僚管理、财政、合法性、宫廷斗争。
- **魅力**：招揽、士气、声望、文化影响。

不要给所有名将都堆高统率；用 `weaknesses` 与 `traits` 制造差异。

### 1.3 人物类型

| 类型 | 玩法功能 | 例子 |
|---|---|---|
| 君主 | 合法性、继承、外交 | 曹操、刘备、柴荣、钱镠 |
| 谋臣 | 政策、情报、外交 | 荀彧、诸葛亮、赵普 |
| 将领 | 战斗、征兵、边疆 | 关羽、韩信（跨期）、李存勖 |
| 文官 | 财政、行政、科举 | 刘晏、杨炎 |
| 宦官/外戚 | 宫廷、情报、腐败 | 高力士、田令孜 |
| 藩镇 | 地方兵权、忠诚度 | 安禄山、朱温 |
| 文化人物 | 声望、科技、宗教 | 李白、杜甫、玄奘 |
| 外族首领 | 骑兵、贸易、和亲 | 耶律阿保机、松赞干布 |

### 1.4 关系网

`relationships[].type` 可用：

```text
君臣, 父子, 兄弟, 夫妻, 师徒, 盟友, 对手, 政敌, 降附, 被杀
```

设计建议：

- **关系是双向的**：A 对 B 是“君臣”，B 对 A 可能是“猜忌”。
- **关系会变化**：用事件触发关系翻转（盟友→政敌、君臣→被杀）。
- **关系有代价**：杀功臣会降低招揽率；背盟会降低外交信誉。
- **关系网是玩法**：招募一个人，可能带来他的门生、部曲、敌人。

示例：

- 曹操—荀彧：早期君臣，后期因称公分歧；可设计“劝进/反对”分支。
- 关羽—刘备：君臣+兄弟；关羽败亡触发刘备伐吴。
- 钱镠—董昌：旧主与部下；董昌称帝触发钱镠讨伐。
- 柴荣—赵匡胤：君臣；柴荣早逝触发陈桥兵变。

### 1.5 人物卡输出模板

```markdown
### 人物：柴荣（chai-rong）
- 时代：五代
- 阵营：后周
- 角色：皇帝、改革者、军事统帅
- 性格：果断、务实、急躁、志向远大
- 关键事件：高平之战、世宗改革、北伐契丹
- 游戏定位：高统率/高政治，低寿命；改革线核心
- 关系：郭威（养父子）、赵匡胤（君臣）
- 来源：JIUWUDAISHI、XINWUDAISHI、ZIZHITONGJIAN
- 可信度：A
```

## 2. 事件卡

### 2.1 字段结构

```json
{
  "id": "gaoping",
  "name": "高平之战",
  "year": 954,
  "end_year": 954,
  "period": "五代",
  "type": "battle",
  "location_id": "gaoping",
  "factions": ["later-zhou", "northern-han", "liao"],
  "characters": ["chai-rong", "liu-chong", "zhao-kuangyin"],
  "summary": "……",
  "causes": "……",
  "course": "……",
  "outcome": "……",
  "significance": "……",
  "game_hooks": ["御驾亲征", "阵前逆转", "禁军整编"],
  "sources": ["JIUWUDAISHI", "XINWUDAISHI", "ZIZHITONGJIAN"],
  "reliability": "A"
}
```

### 2.2 事件类型与玩法

| 类型 | 玩法映射 | 例子 |
|---|---|---|
| `war` | 全面战争、多战役 | 安史之乱、黄巢起义 |
| `battle` | 单场决战、战术关卡 | 官渡之战、淝水之战、高平之战 |
| `rebellion` | 内乱、平叛、民心 | 黄巾起义、六镇起义 |
| `coup` | 宫廷政变、暗杀、禁军 | 玄武门之变、陈桥兵变 |
| `succession` | 继承危机、合法性 | 曹丕代汉、司马炎代魏 |
| `reform` | 政策树、制度升级 | 两税法、世宗改革 |
| `treaty` | 外交、割地、和亲 | 澶渊之盟（宋初以后）、燕云割让 |
| `massacre` | 恐怖事件、士气/民心 | 屠城、白马之祸 |
| `migration` | 人口流动、侨郡 | 永嘉南渡 |
| `disaster` | 灾害、疫病、饥荒 | 大疫、黄河决口 |
| `cultural` | 文化、科技、声望 | 兰亭雅集、雕版印九经 |
| `religious` | 宗教、寺院、合法性 | 佛教兴盛、灭佛 |
| `administrative` | 行政改革、区划 | 三省六部、削藩 |
| `diplomatic` | 外交、册封、联盟 | 契丹册封、吴越称臣 |

### 2.3 事件链

单个事件只是节点；事件链才有叙事。建议用“因果边”连接：

```text
灾荒 → 起义 → 中央募兵 → 军阀坐大 → 决战 → 新朝
```

示例：安史之乱链

```text
节度使坐大 → 安史之乱 → 洛阳陷落 → 马嵬驿之变
→ 灵武称帝 → 太原保卫战 → 邺城之战 → 史朝义弑父
→ 安史之乱平定 → 藩镇割据
```

示例：五代链

```text
后梁建立 → 柏乡之战 → 后唐灭后梁 → 兴教门之变
→ 明宗之治 → 后晋割燕云 → 契丹灭后晋 → 后周建立
→ 高平之战 → 世宗改革 → 陈桥兵变
```

### 2.4 分支设计

历史事件不必强制按原结果发生。可以设计：

- **提前/延后**：玩家改革成功，安史之乱推迟或规模缩小。
- **换人**：关键人物死亡/存活，事件走向不同。
- **换阵营**：玩家说服敌方将领倒戈。
- **换结果**：战术胜利但战略失败；守住都城但失去粮道。
- **隐藏条件**：财政、民心、合法性、外援达到阈值才触发。

分支要有**历史重量**：偏离越远，后续事件越不稳定，而不是简单“更好”。

### 2.5 事件卡输出模板

```markdown
### 事件：高平之战（gaoping）
- 年份：954
- 类型：battle
- 地点：gaoping（山西高平）
- 阵营：后周 vs 北汉 + 契丹
- 人物：柴荣、刘崇、赵匡胤
- 起因：后周世宗新立，北汉联合契丹南下
- 经过：后周右军溃退，柴荣亲临阵前，赵匡胤等力战逆转
- 结果：北汉大败，后周威望大振，禁军开始整编
- 意义：五代后期强弱转折，为世宗改革与北宋统一奠基
- 游戏钩子：御驾亲征、阵前逆转、禁军整编
- 来源：JIUWUDAISHI、XINWUDAISHI、ZIZHITONGJIAN
```

## 3. 叙事节奏

### 3.1 四幕结构

1. **秩序**：介绍政权、制度、人物关系。
2. **裂痕**：灾荒、继承、边患、党争。
3. **崩解**：战争、政变、流亡、背叛。
4. **重组**：新秩序、改革、统一或割据。

### 3.2 节奏控制

- 不要连续放 5 个大战；用内政、外交、人物线调节。
- 大战前给玩家准备窗口：征兵、屯粮、结盟、离间。
- 大战后给玩家消化窗口：封赏、整编、安抚、追责。
- 用“小事件”铺垫“大事件”：谣言、灾异、粮价、流民、刺客。

### 3.3 视角

- **君主视角**：合法性、继承、财政、朝堂。
- **将领视角**：战役、士气、粮道、战功。
- **地方视角**：民生、水利、宗族、盗匪。
- **外族视角**：迁徙、贸易、联盟、南下。

多视角可以让同一事件有不同解释，增加重玩价值。
