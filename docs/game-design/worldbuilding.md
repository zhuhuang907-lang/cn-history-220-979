# 世界构建：时代、政权与地理

本文说明如何用 `data/periods.json`、`data/game/factions.json` 与 `data/game/locations.json` 搭建一个可玩的历史世界。

---

## 1. 选择时代段落

`data/periods.json` 提供 15 个段落。每个段落有 `summary`、`themes`、`game_hooks`、`key_events`、`sources`。

| 时代 | 时间 | 核心矛盾 | 推荐玩法 |
|---|---|---|---|
| 东汉末 | 184–220 | 中央崩解、州牧军阀化 | 乱世开局、挟天子、联盟背叛 |
| 三国 | 220–280 | 三足鼎立、正统之争 | 北伐、水战、人才与后勤 |
| 西晋 | 266–316 | 统一速亡、宗室与门阀 | 宗王出镇、八王之乱、永嘉崩局 |
| 东晋 | 317–420 | 门阀共治、北伐与内乱 | 侨旧士族、北伐声望、桓玄之变 |
| 十六国 | 304–439 | 民族政权、胡汉分治 | 部族联盟、迁徙、短命王朝 |
| 南朝 | 420–589 | 寒人掌权、南北对峙 | 宫廷政变、水军、佛教经济 |
| 北朝 | 386–581 | 胡汉融合、军镇与均田 | 改革、六镇、东西对峙 |
| 隋 | 581–618 | 统一与过度动员 | 运河工程、征高句丽、隋末群雄 |
| 初唐 | 618–712 | 建国、贞观、武周革命 | 关陇集团、玄武门、女皇政治 |
| 盛唐 | 712–755 | 盛世与边镇坐大 | 节度使、丝路、安史前夜 |
| 中唐 | 755–835 | 藩镇、宦官、财政改革 | 河朔三镇、神策军、两税法 |
| 晚唐 | 835–907 | 宦官与藩镇夹击、农民起义 | 黄巢流民军、军阀兼并、唐亡 |
| 五代 | 907–960 | 政权速替、牙兵与契丹 | 禁军拥立、燕云、世宗改革 |
| 十国 | 902–979 | 南方割据、保境安民 | 水网、海贸、词与佛教、归宋 |
| 宋初统一 | 960–979 | 先南后北、削藩 | 陈桥兵变、杯酒释兵权、统一战争 |

### 1.1 开局年怎么选

- **看合法性危机**：老政权衰亡、幼主即位、权臣崛起。
- **看军事转折**：大败、围城、叛变、外敌入侵。
- **看制度窗口**：改革、迁都、立储、削藩。
- **看玩家位置**：选择一个“有选择但不多”的势力，避免一开局就无敌或必亡。

示例：

- 三国剧本可从 **219 年** 开局：关羽北伐、吕蒙偷袭、曹操将死，三方都有动作。
- 中唐剧本可从 **755 年** 开局：安禄山起兵，唐廷需要决定守潼关还是弃长安。
- 五代剧本可从 **954 年** 开局：后周世宗刚即位，北汉与契丹来攻，高平之战一触即发。
- 宋初剧本可从 **960 年** 开局：陈桥兵变，玩家决定先南还是先北。

## 2. 政权设计

### 2.1 政权类型

`factions.json` 的 `type` 枚举：

```text
empire, kingdom, dynasty, warlord, regional-regime,
tribal-confederation, rebel, garrison, city-state
```

不同类型的玩法重点：

| 类型 | 玩法重点 | 例子 |
|---|---|---|
| `empire` | 正统、官僚、多战线 | 东汉、唐、北宋 |
| `kingdom` | 区域防御、外交平衡 | 蜀汉、吴越、南唐 |
| `dynasty` | 继承、宫廷、改革 | 后梁、后唐、后周 |
| `warlord` | 个人威望、私兵、兼并 | 曹操、袁绍、朱温 |
| `regional-regime` | 地方资源、保境安民 | 十国诸政权 |
| `tribal-confederation` | 部族联盟、迁徙、骑兵 | 契丹、柔然、吐蕃 |
| `rebel` | 动员、流动作战、合法性 | 黄巾军、黄巢军 |
| `garrison` | 军镇、粮道、中央关系 | 朔方镇、魏博镇 |
| `city-state` | 贸易、城防、外交 | 西域绿洲城邦 |

### 2.2 政权卡字段

```json
{
  "id": "later-zhou",
  "name": "后周",
  "type": "dynasty",
  "period": "五代",
  "start": 951,
  "end": 960,
  "capital": "开封",
  "territory": "中原",
  "founders": ["郭威"],
  "key_rulers": ["郭威", "柴荣"],
  "allies": [],
  "enemies": ["northern-han", "liao"],
  "ideology": "中原正统与改革",
  "military": "禁军",
  "economy": "中原农业、漕运",
  "strengths": ["禁军", "改革"],
  "weaknesses": ["继承", "北方威胁"],
  "game_hooks": ["高平之战", "世宗改革", "陈桥兵变"],
  "sources": ["JIUWUDAISHI", "XINWUDAISHI", "ZIZHITONGJIAN"],
  "reliability": "A"
}
```

设计时重点看：

- `strengths` / `weaknesses`：决定阵营风格，不要只看疆域大小。
- `allies` / `enemies`：决定外交网与开局战争。
- `ideology`：决定合法性来源（汉室、唐室、契丹册封、地方自治）。
- `military` / `economy`：决定兵种与资源结构。
- `game_hooks`：直接转成事件、科技、政策或剧本目标。

### 2.3 合法性系统

中古政权的合法性来源多样，可做成不同资源：

| 来源 | 表现 | 例子 |
|---|---|---|
| 天命/禅让 | 受禅、符瑞、郊祀 | 曹丕代汉、司马炎代魏 |
| 血统/宗室 | 继承、宗庙、封爵 | 东晋、南朝 |
| 唐室继承 | 奉唐正朔、复唐 | 后唐 |
| 军事强权 | 禁军拥立、藩镇推戴 | 五代 |
| 地方民生 | 保境安民、水利、减税 | 吴越、南唐 |
| 外族册封 | 契丹册封、和亲 | 后晋、北汉 |
| 宗教 | 佛教、道教、太平道 | 南朝、黄巾 |

合法性可以设计成**可消耗资源**：战争失败、弑君、背盟、灾异都会削弱；改革、赈灾、胜战、外交承认可以恢复。

## 3. 地理与地图

### 3.1 地点类型

`locations.json` 的 `type` 枚举：

```text
capital, city, fortress, pass, region, river, port, religious-site, battlefield
```

地图节点建议：

- **都城**：政治中心，失守则合法性大跌。
- **关隘**：一夫当关，控制交通线。
- **河流/港口**：水军、漕运、贸易。
- **战场**：历史事件触发点，可做特殊地形。
- **宗教圣地**：信仰、旅游、动员。
- **区域**：大范围地形，提供补给与征兵修正。

### 3.2 地理分层

建议把地图做成三层：

1. **战略层**：州/道/路，决定行政区与资源。
2. **战役层**：城、关、渡口、战场，决定行军与补给。
3. **战术层**：具体战斗地形，决定阵型与兵种。

### 3.3 关键地理走廊

- **关中—汉中—巴蜀**：秦岭、阳平关、剑阁、祁山。
- **中原—河北**：黄河、太行山、邺城、幽州。
- **江淮—江南**：淮河、长江、采石、京口、建康。
- **荆楚—岭南**：襄阳、江陵、湘水、五岭。
- **河东—关中**：太原、蒲坂、潼关。
- **燕云—塞北**：幽州、云州、居庸关、古北口。
- **河西—西域**：凉州、玉门、高昌、龟兹。

### 3.4 补给与后勤

中古战争的后勤限制比战术更重要：

- 粮道长度决定出兵规模。
- 水运比陆运便宜，江淮、运河、长江是战略资源。
- 骑兵需要牧场与草料，不能无限深入。
- 围城战受季节、疫病、援军影响。
- 大军久驻会消耗地方，引发民变或兵变。

游戏里可以用“粮道节点 + 补给半径 + 季节修正”来表现，而不是单纯堆兵力。

## 4. 冲突循环

不同时代的核心循环不同：

### 4.1 乱世开局（东汉末、隋末、晚唐）

```text
灾荒/起义 → 中央失能 → 地方募兵 → 军阀兼并 → 合法性争夺 → 新王朝
```

玩法重点：招兵、屯田、外交、挟天子、招揽士族。

### 4.2 南北对峙（东晋、南朝、北朝）

```text
北伐/南征 → 边境拉锯 → 内部权斗 → 财政与兵源 → 和战选择
```

玩法重点：水军、侨郡、门阀、正统宣传。

### 4.3 藩镇—中央（中唐、晚唐）

```text
中央削藩 → 藩镇联合反抗 → 战争/妥协 → 财政改革 → 新一轮失衡
```

玩法重点：节度使忠诚、牙兵、盐铁、神策军、党争。

### 4.4 五代速替（五代）

```text
禁军拥立 → 新朝合法性不足 → 藩镇/契丹压力 → 改革或崩溃 → 再兵变
```

玩法重点：禁军忠诚、义儿军、燕云、契丹干预、继承危机。

### 4.5 南方割据（十国）

```text
保境安民 → 水利/海贸 → 中原册封 → 邻国战争 → 归宋/抵抗
```

玩法重点：水网、港口、财政、佛教、词文化、外交称臣。

### 4.6 统一战争（宋初）

```text
陈桥兵变 → 稳定内部 → 先南后北 → 削藩 → 统一
```

玩法重点：禁军改革、杯酒释兵权、后勤、招降、避免两线作战。
