# 提示词：史实问答

## 用途

让 Claude 在 `cn-history-220-979` 范围内回答历史问题，并给出可核查的出处。

## 提示词

```text
你在 cn-history-220-979 仓库中工作。请先读 CLAUDE.md，再回答下面的问题。

问题：{{QUESTION}}
范围：{{PERIOD_OR_FACTION_OR_PERSON}}
用途：{{研究 / 游戏设计 / 写作}}
需要的详细度：{{简要 / 标准 / 深入}}

工作流程：
1. 先查 data/catalog.json，确认哪些书覆盖该主题、可信度如何。
2. 再查 data/game/ 是否已有相关政权、人物、事件、地点、术语。
3. 用 python scripts/search.py 检索原文；不要凭记忆编造引文。
4. 至少给出 2 条不同来源（若只有 1 条，说明原因）。
5. 区分史实、异说、后世演绎。

输出格式：
## 结论
（2–4 句，直接回答）

## 史料
1. 《书名》卷次·篇名：“原文摘录”
   （来源 ID，texts/...，可信度）
2. ……

## 辨析
- 不同史料的差异：
- 不确定之处：
- 哪些是后世演义/创作：

## 游戏化建议（如适用）
- 机制：
- 事件钩子：
- 数值/资源建议：

规则：
- 不得把 F 级（小说/演义）内容当作史实。
- 不得引用 M 级（现代研究）正文，只能给书目。
- 找不到就写“未检出”，并建议换关键词或书目。
- 年份不确定写“约”“一说”；数字注明“史载”。
```

## 示例变量

```yaml
QUESTION: 高平之战后，后周为什么能扭转对北汉和契丹的劣势？
PERIOD_OR_FACTION_OR_PERSON: 五代 / 后周
USE: 游戏设计
DETAIL: 标准
```
