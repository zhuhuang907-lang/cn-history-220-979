# 提示词：政权简报

## 用途

为一个政权生成可用于游戏设计、写作或研究的简报。

## 提示词

```text
你在 cn-history-220-979 仓库中工作。请先读 CLAUDE.md。

任务：为 {{FACTION_NAME}}（{{FACTION_ID}}）生成一份政权简报。
用途：{{游戏阵营设计 / 小说设定 / 研究综述}}
详细度：{{简要 / 标准 / 深入}}

步骤：
1. 从 data/game/factions.json 读取该政权条目。
2. 从 data/game/characters.json 找该政权的人物。
3. 从 data/game/events.json 找相关事件。
4. 从 data/game/locations.json 找都城、关键地点。
5. 用 python scripts/search.py 检索原文，补充细节与引文。
6. 检查 data/game/disambiguation.json，避免同名混淆。

输出：
## 基本信息
- 名称/别名：
- 类型：
- 时代：
- 起止：
- 都城：
- 疆域：
- 建立者/关键君主：

## 政治与合法性
- 合法性来源：
- 制度：
- 内部矛盾：

## 军事
- 兵源：
- 兵种：
- 强弱：
- 关键战役：

## 经济
- 基础：
- 财政：
- 贸易/水利：

## 外交
- 盟友：
- 敌人：
- 册封/朝贡/和亲：

## 人物
| 人物 | 角色 | 关系 | 关键事件 |
|---|---|---|---|

## 事件钩子（5–8 个）
| 事件 | 年份 | 类型 | 玩法用途 |
|---|---|---|---|

## 游戏化建议
- 阵营风格：
- 核心机制：
- 胜利路径：
- 失败条件：
- 独特单位/政策：

## 来源与可信度
- 主要来源：
- 可信度：
- 不确定之处：

规则：
- 不得编造人物、事件、年份。
- 区分史实与设计建议。
- 演义/影视内容标 F。
```

## 示例变量

```yaml
FACTION_NAME: 后周
FACTION_ID: later-zhou
USE: 游戏阵营设计
DETAIL: 标准
```
