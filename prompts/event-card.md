# 提示词：事件卡

## 用途

把一个历史事件转成可玩的事件卡、事件链节点或剧本关卡。

## 提示词

```text
你在 cn-history-220-979 仓库中工作。请先读 CLAUDE.md 和 docs/game-design/characters-events.md。

任务：为 {{EVENT_NAME}} 生成事件卡。
用途：{{游戏事件 / 剧本关卡 / 历史叙事}}
详细度：{{简要 / 标准 / 深入}}
玩法类型：{{战略事件 / 战役 / 政变 / 改革 / 外交 / 灾害}}

步骤：
1. 从 data/game/events.json 读取条目；若不存在，说明并给出新增建议。
2. 查 factions、characters、locations 补上下文。
3. 用 python scripts/search.py 检索原文，找 2–3 条材料。
4. 查同一时代的前后事件，建立因果链。
5. 区分史实、异说、后世演绎。

输出：
## 事件卡
- 名称/别名：
- 年份/持续时间：
- 类型：
- 地点：
- 参战方：
- 关键人物：
- 结果：
- 意义：

## 叙事
- 起因：
- 经过：
- 转折：
- 结局：
- 后续影响：

## 史料
1. 《书名》卷次：“原文”
   （来源 ID，可信度）
2. ……

## 游戏化
- 触发条件：
- 玩家选择（2–4 个）：
- 每个选择的后果：
- 资源/合法性/关系变化：
- 失败与撤退：
- 隐藏条件：

## 事件链
（前因 1–2 个、后果 2–3 个，引用 events.json 的 id）

## 平衡检查
- 是否只有一个最优解？
- 失败是否仍有内容？
- 是否受粮草/季节/地形限制？
- 是否改变后续事件？

规则：
- 事件 type 必须使用 schema 枚举。
- 不得编造年份、参战方、结果。
- 演义/影视桥段标 F。
- 数值用区间/量级，注明“史载/设计”。
```

## 示例变量

```yaml
EVENT_NAME: 高平之战
USE: 游戏事件
DETAIL: 标准
TYPE: 战役
```
