# 提示词：人物卡

## 用途

把史料中的人物转成可玩的人物卡，保留来源与可信度。

## 提示词

```text
你在 cn-history-220-979 仓库中工作。请先读 CLAUDE.md 和 docs/game-design/characters-events.md。

任务：为 {{PERSON_NAME}} 生成人物卡。
用途：{{游戏角色 / 小说人物 / 研究小传}}
详细度：{{简要 / 标准 / 深入}}
玩法定位：{{君主 / 谋臣 / 将领 / 文官 / 藩镇 / 文化人物 / 其他}}

步骤：
1. 从 data/game/characters.json 读取条目；若不存在，说明并给出新增建议。
2. 查 data/game/factions.json、events.json、locations.json 补上下文。
3. 查 data/game/disambiguation.json，避免同名人物混淆。
4. 用 python scripts/search.py 检索原文，找 1–3 条可引用材料。
5. 区分史实、史家评价、后世演绎。

输出：
## 人物卡
- 姓名/别名：
- 时代：
- 阵营：
- 生卒：
- 籍贯：
- 角色：
- 性格标签：
- 关键事件：
- 关系网：

## 史实小传
（150–300 字，按时间线）

## 史料
1. 《书名》卷次：“原文”
   （来源 ID，可信度）
2. ……

## 游戏化
- 属性建议（统率/武力/智谋/政治/魅力，1–10）：
- 特质：
- 技能：
- 招募/忠诚条件：
- 关系事件：
- 失败/死亡事件：

## 叙事钩子
- 可写的冲突：
- 可用的台词/典故：
- 需要避免的演义化：

规则：
- 生卒、籍贯不确定写“约/传/一说”。
- 不得把演义情节写成史实；如使用，标 F。
- 不得伪造引文与卷次。
```

## 示例变量

```yaml
PERSON_NAME: 钱镠
USE: 游戏角色
DETAIL: 标准
ROLE: 君主
```
